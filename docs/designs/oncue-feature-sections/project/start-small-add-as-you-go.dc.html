Ask Claude to “set up OnCue”. It checks each tool, installs what it can, and tells you which outputs are ready.

No ElevenLabs?

Record the narration yourself and attach the MP3, with a words.json from any word-level transcriber. With neither, you still get the storyboard, the deck and a silent preview.
