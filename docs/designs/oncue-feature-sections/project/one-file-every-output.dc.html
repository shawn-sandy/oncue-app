One source of truth

One file. Every output.

Claude writes your explainer into short.json: each beat’s voiceover line, its scene, and the word each element enters on. The storyboard, the script, the deck and the video are all built from that one file, so they always match.

Built from it

  1. 01

    Storyboard

    A beat list with preview stills, or a Design canvas.

  2. 02

    Voiceover script

    Every vo line in order, read in one take for a consistent voice.

  3. 03

    Editable deck

    Real PowerPoint text and shapes in your colours, with the voiceover in the speaker notes.

  4. 04

    Finished video

    An MP4 at the spec’s size, 30fps, H.264 with AAC audio.

Change it in one place

To change the copy, edit short.json, or ask Claude to, and rebuild. Every output picks up the change.

An edit made only in the .pptx leaves the deck and the video out of step.
